# 🔐 Gerador de Senhas

Projeto desenvolvido para praticar **JavaScript, lógica de programação e manipulação do DOM**.

A aplicação gera senhas automaticamente, utilizando caracteres definidos pelo código para criar combinações aleatórias.

## ✨ Funcionalidades

- 🔐 Geração automática de senhas
- 🎲 Criação de combinações aleatórias
- ⚡ Geração de uma nova senha a cada execução
- 🖥️ Exibição da senha diretamente na interface
- 🧠 Uso de lógica JavaScript para seleção aleatória de caracteres

## 🛠️ Tecnologias utilizadas

- 🌐 HTML5
- 🎨 CSS3
- ⚡ JavaScript

## 🎯 Objetivo do projeto

Este projeto foi desenvolvido com o objetivo de praticar conceitos fundamentais de JavaScript, principalmente:

- Variáveis
- Funções
- Estruturas de repetição
- Manipulação de strings
- Números aleatórios com `Math.random()`
- Manipulação do DOM
- Eventos
